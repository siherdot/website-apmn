# Data resmi yang masih dibutuhkan

Isi ini sengaja tidak ditebak. Kirim data resmi perseroan untuk melengkapi halaman:

- [ ] Dewan Komisaris: nama lengkap, jabatan (Komisaris Utama / Komisaris), riwayat singkat.
- [ ] Dewan Direksi: nama lengkap, jabatan, riwayat singkat.
- [ ] Laporan keuangan: tahun, file final hasil audit, tautan unduh resmi.
- [ ] RUPS: file risalah/panggilan/surat kuasa/tata tertib/pengumuman yang masih berlaku. Situs lama memakai placeholder `www.isilinkpdf.com` — jangan dipindahkan.
- [ ] Video profil: tautan resmi (YouTube/Vimeo/Drive) + izin penggunaan.
- [ ] Laporan tahunan: pastikan tautan Google Drive yang dipakai masih aktif dan dapat diakses publik.

Setelah data diterima, sunting `lib/content.ts`, jalankan `npm run build`, lalu commit/push. Belum ada deploy.
